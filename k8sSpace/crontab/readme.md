# creating a custom resource
https://kubernetes.io/docs/tasks/extend-kubernetes/custom-resources/custom-resource-definitions/?ref=techblog&utm_source=copilot.com


1. create file resourcedefinition.yaml
2. `kubectl apply -f resourcedefinition.yaml`
3. `kubectl apply -f my-crontab.yaml`
4. `kubectl get crontab`
5. `kubectl get ct -o yaml`
